# Animasi Hati

Proyek ini menampilkan animasi hati berbentuk partikel 3D dengan warna yang berubah secara halus.

## Struktur file

- `index.html` — halaman utama.
- `style.css` — tampilan halaman.
- `script.js` — logika animasi.

## Menjalankan proyek

Buka `index.html` di browser. Proyek memuat Three.js dan GSAP dari CDN, jadi koneksi internet diperlukan.
